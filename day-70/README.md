# Parth Agashe — Portfolio (Placeholder)

A basic personal portfolio site, built as part of Day 70 of Angela Yu's 100 Days of Code — the git & GitHub fundamentals lesson.

🔗 Live: https://parthagashe27.github.io/parth-portfolio/

## Why this exists
Day 70 is about learning git/GitHub version control by building and deploying a real site with it, instead of just uploading finished files. This repo is that exercise — practicing `git init`, `add`, `commit`, and `push` on an actual project, then deploying it live via GitHub Pages.

## Status
This is a placeholder using the HTML5 UP "Identity" template. Content (bio, social links, projects) is not final and will be updated once I have real projects to showcase.

## Stack
- HTML / CSS (HTML5 UP "Identity" template)
- Deployed via GitHub Pages

## Origin
Originally built as Day 56 of my [100 Days of Code repo](https://github.com/ParthAgashe27/100-days-of-python) as a Flask app; converted to static HTML for GitHub Pages deployment on Day 70.
